# نظام العميد للاستيراد والتصدير

منصة لإدارة استيراد السيارات من الولايات المتحدة إلى سلطنة عُمان، وتتكون من:
- **الموقع العام** `/`: صفحة تعريفية يمكن تعديل محتواها بالكامل من لوحة الإدارة.
- **لوحة الإدارة** `/admin`: العملاء، السيارات، الصور والمستندات، مراحل الاستيراد، مواعيد الوصول، الدفعات والإيصالات، كشوف الحساب، المصروفات، التقارير، الإشعارات، الموظفون والصلاحيات، الإعدادات، سجل النشاط، النسخ الاحتياطي.
- **بوابة العميل** `/login` ثم `/portal`: يرى العميل سياراته فقط، مع الصور ومراحل الشحن وموعد الوصول والمدفوع والمتبقي والإيصالات والمستندات.

## التقنيات
Laravel 11 · PHP 8.2+ · MySQL/MariaDB · Bootstrap 5 RTL · JavaScript/AJAX · mPDF (PDF بالعربية) · PhpSpreadsheet (Excel).
لا يحتاج Node.js. مكتبات الواجهة محفوظة داخل `public/assets/vendor` (لا اعتماد على CDN، عدا خطوط Google).

## التثبيت المحلي
```bash
composer install
cp .env.example .env        # عدّل بيانات قاعدة البيانات
php artisan key:generate
php artisan migrate --seed  # ينشئ الجداول وحساب المدير ومراحل الاستيراد والإعدادات
php artisan serve
# اختياري للتجربة فقط: php artisan db:seed --class=DemoSeeder
```
بيانات المدير الأولى من `.env`: `ADMIN_USERNAME` / `ADMIN_PASSWORD` (الافتراضي admin / ChangeMe@2026) — **غيّرها فورًا** من «حسابي».

## النشر على Hostinger (استضافة مشتركة)
1. **قاعدة البيانات**: hPanel → Databases → MySQL Databases، أنشئ قاعدة ومستخدمًا.
2. **تجهيز الملفات محليًا**: `composer install --no-dev --optimize-autoloader` ثم اضغط المشروع كاملًا (مع `vendor`) في ملف zip.
3. **الرفع**: File Manager → `public_html` → ارفع الملف وفك الضغط بحيث يكون `artisan` مباشرة داخل `public_html`.
   ملف `.htaccess` الموجود في الجذر يوجّه كل الطلبات إلى `public/` ويمنع الوصول إلى `.env` والمجلدات الداخلية ويفرض HTTPS.
   (بديل أكثر أمانًا: ضع المشروع في `~/alameed` وانقل محتويات `public` إلى `public_html` وعدّل مسارات `index.php` إلى `__DIR__.'/../alameed/...'`.)
4. **‎.env**: انسخ `.env.example` إلى `.env` واملأ بيانات القاعدة و`APP_URL=https://نطاقك` والبريد (SMTP Hostinger)، واترك `APP_DEBUG=false`.
5. **إنشاء الجداول** (اختر أحد الطريقين):
   - عبر SSH (متاح في خطط Premium/Business): `php artisan key:generate && php artisan migrate --seed --force && php artisan config:cache && php artisan route:cache && php artisan view:cache`
   - بدون SSH: استورد `database/alameed.sql` من phpMyAdmin (يحتوي الجداول + المدير admin / ChangeMe@2026 + المراحل + الإعدادات)، وولّد `APP_KEY` محليًا بـ `php artisan key:generate --show` وضعه في `.env`.
   > ملاحظة: الرقم المدني يُشفّر بـ `APP_KEY` — لا تغيّر المفتاح بعد إدخال البيانات.
6. **الصلاحيات**: يجب أن يكون `storage/` و`bootstrap/cache/` قابلين للكتابة (755).
7. **SSL**: hPanel → Security → SSL → فعّل الشهادة المجانية.
8. **Cron** (hPanel → Advanced → Cron Jobs) كل دقيقة:
   `cd /home/USER/public_html && php artisan schedule:run >> /dev/null 2>&1`
   يشغّل تنبيهات مواعيد الوصول يوميًا (07:00) والنسخ الاحتياطي اليومي (02:00). عند عدم تفعيله تعمل التنبيهات مرة يوميًا عند فتح لوحة التحكم، ويمكن عمل نسخة يدوية من الإعدادات → النسخ الاحتياطي.

## الأمان
- كلمات المرور bcrypt (`password_hash`/`password_verify`)، حماية CSRF لكل النماذج، Eloquent/Query Builder يمنع SQL Injection.
- الحد من محاولات الدخول (5 محاولات / 15 دقيقة لكل حساب، و30 لكل IP).
- كل صلاحية يتم التحقق منها في الخادم (Gates + Middleware)، والعميل لا يصل إلا لبياناته (فحص الملكية → 404).
- الصور والمستندات مخزنة في `storage/app/private` خارج المجلد العام، وتُقدَّم عبر مسارات تتحقق من الدخول والملكية؛ يتم فحص نوع الملف الفعلي (MIME) وحجمه.
- الرقم المدني مشفّر في القاعدة، ويُعرض مخفيًا جزئيًا (•••••1234)، ويُبحث عنه ببصمة HMAC.
- الدفعات لا تُحذف؛ الإلغاء موثق بالسبب والموظف والتاريخ. جميع العمليات الحساسة في سجل النشاط.
- المبالغ `DECIMAL(14,3)`، والحسابات تتم بأعداد صحيحة (بيسة) بلا أخطاء تقريب. **المتبقي = المستحق − الدفعات المعتمدة** ولا يُدخل يدويًا.

## صلاحيات الموظفين
يحددها المدير من «الموظفون والصلاحيات»: عرض/إدارة العملاء، عرض/إدارة السيارات، تحديث الحالات والمواعيد، رفع الصور والمستندات، عرض المالية، تسجيل الدفعات والمصروفات وتعديل المبالغ، إلغاء الدفعات، التقارير، إدارة المراحل، الاستفسارات. الموظف بدون صلاحية المالية لا يرى أي أرقام مالية.
